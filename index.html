Pertanyaan Umum (FAQ)

Yang paling sering ditanyakan pelanggan.

Bagaimana cara pemesanannya?

Sangat mudah! Kamu tinggal pilih produk di katalog, pilih nominal/paket yang dimau, isi nomor WhatsApp dan ID (jika game), lalu klik Checkout. Sistem akan otomatis menampilkan QRIS pembayaran dengan harga tepat.

Kapan pesanan saya dikirim?

Setelah kamu menekan tombol "Saya Sudah Bayar" pada form QRIS, pesanan otomatis masuk ke sistem Admin. Saat Admin menyetujui, produk berupa Game akan langsung masuk ke ID kamu, dan untuk Produk Aplikasi (Email/Password), informasinya akan langsung muncul tertulis di Web ini tepat di menu "Pesanan / Lacak Pesanan".

Apakah produk bergaransi?

Tentu! Semua produk bergaransi sesuai syarat dan ketentuan masing-masing aplikasi/game. Jika akun terkendala, opsi tombol komplain "Akun Bermasalah" akan otomatis muncul di riwayat pesanan setelah pesanan berstatus Sukses.
